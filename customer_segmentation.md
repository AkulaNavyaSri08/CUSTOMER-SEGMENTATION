# Customer Segmentation Using Machine Learning

## Overview
This project performs customer segmentation using K-Means Clustering based on customer income and spending behavior. The goal is to identify different customer groups for better business insights and targeted marketing strategies.

---
<a href ="https://github.com/AkulaNavyaSri08/CUSTOMER-SEGMENTATION/blob/main/customer_segmentation.csv">Customer segmentation</a>
## Features
- Customer segmentation using K-Means Clustering
- Income and spending behavior analysis
- Data visualization using scatter plots and charts
- Excel pivot table analysis
- Elbow Method for optimal cluster selection

---

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Microsoft Excel
- Visual Studio Code
